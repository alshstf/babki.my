# Каталог тарифов кредитных карт

Решение Р-32: числа тарифов банков — здесь, по файлу на карту; программа
встраивает их при сборке, и в условиях карты можно выбрать «мою карту» и дату
договора. Сроки и суммы самого банка («Что пишет банк») всё равно главнее.

Каждый файл — одна карта банка:

- `id` — постоянный, латиницей; на него ссылаются карты семей.
- `bank`, `card` — как назвать для человека.
- `versions` — тариф по датам договора: `contracts_from` / `contracts_to`
  (`null` — без границы), `revision` — дата редакции тарифа, `checked_on` —
  когда сверено с первоисточником, `sources` — ссылки на документы банка,
  `notes` — что важно знать, `terms` — поля условий карты в тех же именах, что
  в API (`CreditCardTerms`), только те, что задаёт тариф. Личное (лимит,
  ставка из диапазона, дата договора) сюда не пишется.

Правка — PR: у каждого изменённого числа ссылка на документ банка. Тест
`TestTheCatalogHolds` проверяет, что из каждой версии получаются годные
условия.
