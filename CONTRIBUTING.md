# Контрибуции

Проект в pre-alpha: интерфейсы нестабильны, большие PR не принимаются —
сначала откройте issue и обсудите.

## CLA

Для принятия контрибуций потребуется подписание CLA (Apache-стиль,
individual/corporate) — автоматизация через CLA Assistant будет включена
до публичного релиза. Без CLA проект не может лицензировать ваш код
по FSL и выполнять обещание Apache-2.0-через-2-года.

## Окружение

- Go ≥1.25, Node 22 LTS, Docker (для тестов с Postgres — testcontainers).
- `make test` — юнит- и интеграционные тесты
- `make test-all` — включая тесты встроенного UI (нужен `make ui`)
- `make lint` — golangci-lint

## Правила

- TDD: сначала падающий тест, затем код. Красный → зелёный → коммит.
- Conventional commits (`feat:`, `fix:`, `docs:`, ...).
- Деньги — только int64 в минорных единицах; количества — decimal.
- Модули `internal/*` общаются только через интерфейсы; чужие таблицы не читать.
