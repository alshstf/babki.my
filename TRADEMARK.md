# Товарные знаки

«babki.my», логотип и доменное имя — идентификаторы проекта и его
будущего управляемого сервиса.

Разрешено без вопросов: упоминать проект по имени, писать «совместимо с
babki.my», «форк babki.my».

Нельзя без письменного разрешения: называть форк или производный продукт
«babki», «babki.my» или созвучно; использовать логотип/домен так, будто
ваш продукт — официальный. Форк должен жить под собственным именем
(прецедент: форк Maybe Finance переименован в Sure).
